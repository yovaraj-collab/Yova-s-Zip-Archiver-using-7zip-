// What It Does
📦

Size-Limited Archives

Splits your files across independent ZIPs, each staying under your chosen MB limit.

🔐

AES-256 Encryption

Password-protect every archive with industry-standard AES-256 via 7-Zip.

📂

Drag & Drop UI

Drop folders directly onto the path fields. No typing long directory paths.

📊

CSV Audit Report

Auto-generates a timestamped CSV showing every file's status and destination archive.

🗂️

Preserve Folder Structure

Optionally store files with their relative paths intact inside each ZIP.

⚡

Sort & Split Volumes

Sort by name, largest, or smallest first. Enable split volumes for oversized single files.

Ready to archive smarter?

Free, open source, no install needed — just run the .bat file on any Windows machine with 7-Zip.
